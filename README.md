# The Artists — Full-Stack Agency Site

Node.js + Express backend with static HTML/CSS/JS frontend.
Bookings are stored server-side in `data/bookings.json` and viewable
at `/admin.html` with the admin key.

## Requirements
- Node.js 18+ (tested on 20)

## Install & run
```bash
npm install
ADMIN_KEY="your-strong-secret" npm start
